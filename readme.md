# 🎲 로또 번호 생성기 (Streamlit)

이 프로젝트는 파이썬(Python)과 Streamlit 라이브러리를 사용하여 구현한 **로또 번호 생성기**입니다. 
사용자가 버튼을 누르면 1부터 45 사이의 중복 없는 숫자 6개를 랜덤하게 추출하여, 실제 로또 공과 같은 입체적인 디자인으로 화면에 보여줍니다.

## ✨ 주요 기능

* **랜덤 번호 추출**: 1~45 사이의 숫자 중 중복되지 않는 6개의 숫자를 오름차순으로 정렬하여 제공합니다.
* **최대 5게임 제한**: '로또번호 생성' 버튼을 누를 때마다 게임이 추가되며, 최대 5게임까지만 생성되도록 제한합니다.
* **직관적인 UI (실제 공 모양)**: 
  * HTML과 CSS의 인라인 스타일을 활용하여 그림자 효과가 적용된 입체적인 공 모양을 구현했습니다. (CSS `class` 미사용)
  * 번호 대역별로 지정된 공식 색상을 적용하여 가독성을 높였습니다.
    * 1 ~ 10: 노란색 🟡
    * 11 ~ 20: 파란색 🔵
    * 21 ~ 30: 빨간색 🔴
    * 31 ~ 40: 회색 ⚫
    * 41 ~ 45: 초록색 🟢
* **상태 유지 (Session State)**: Streamlit의 `session_state`를 활용하여 버튼을 누를 때마다 이전 결과가 사라지지 않고 누적되도록 구현했습니다.

## 🚀 설치 및 실행 방법

### 1. 사전 요구 사항
이 프로그램을 실행하기 위해서는 Python이 설치되어 있어야 합니다.

### 2. 라이브러리 설치
터미널(또는 명령 프롬프트)을 열고 아래 명령어를 입력하여 Streamlit을 설치합니다.
```bash
pip install streamlit
```

### 3. 프로그램 실행
다운로드 받은 `lotto_streamlit.py` 파일이 있는 경로로 이동한 후, 아래 명령어를 실행합니다.
```bash
streamlit run lotto_streamlit.py
```

### 4. 접속
명령어를 실행하면 자동으로 기본 웹 브라우저가 열리며 로또 번호 생성기 페이지(`http://localhost:8501`)로 접속됩니다.
